# Research Basis

This reference captures the external guidance used to shape Anan's mobile AI UX rules.

## OpenAI

- ChatGPT Search: low-friction answers with cited sources and follow-up behavior inform trust-oriented assistant cards.
  - https://help.openai.com/en/articles/9237897-chatgpt-search/
- Temporary Chat: privacy state should be explicit when it materially changes expectations.
  - https://help.openai.com/en/articles/9295248
- Voice Mode FAQ: voice should feel like part of the core chat flow, with clear state and transcript continuity.
  - https://help.openai.com/en/articles/8400625-voice-conversations-beta-faq
- Canvas: when work exceeds normal chat, a separate workspace is better than overloading the composer.
  - https://openai.com/index/introducing-canvas/

## Google PAIR

- Mental models: introduce the AI system and set expectations over time.
- Explainability + trust: decide if, when, and how to show confidence or explanation.
- Feedback + control: give users useful control without overwhelming them.
- Errors + graceful failure: communicate the way forward when the system cannot complete the task.
  - https://pair.withgoogle.com/old-gb/
  - https://pair.withgoogle.com/guidebook-v2/chapters/feedback-controls/

## Apple

- Hierarchy, harmony, and consistency guide how native mobile surfaces should feel coherent and trustworthy.
  - https://developer.apple.com/design/human-interface-guidelines/

## Android

- Adaptive layout quality, privacy, and mobile usability reinforce touch-friendly and structurally clear UI choices.
  - https://developer.android.com/design

## Wellbeing Reminder

- MIT/OpenAI wellbeing reporting is a reminder not to lean into dependence-oriented AI interaction patterns.
  - https://www.media.mit.edu/articles/chatgpt-may-be-making-us-lonelier/
