# AccountScreen

Buyer account hub and shared primitives for the native mobile buyer app.

- `index.tsx` is the calm account overview and router entry point.
- `shared.tsx` contains the reusable account section, stat, row, and empty-state primitives.
- Dedicated detail routes live in sibling feature folders:
  - `AccountProfileScreen/`
  - `AccountSavedScreen/`
  - `AccountHistoryScreen/`
  - `AccountSettingsScreen/`
