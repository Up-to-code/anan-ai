# AnalyticsScreen

Buyer-facing market-intelligence surface for the mobile app.

- `index.tsx` orchestrates the live-or-fallback buyer analytics story, section order, and search handoff CTA.
- `AnalyticsMetricCard.tsx` owns the compact KPI card used in the top summary grid.
- `AnalyticsTrendChart.tsx` renders the calm weekly trend block with bars and lightweight context labels.
