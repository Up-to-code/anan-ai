# Chat Components

Chat-first UI primitives for the simplified client web surface.

- `ChatShell` owns the centered app layout
- `ChatHeader` owns the small top bar
- `ChatConversation` owns the scrollable thread region
- `ChatMessage` renders user and assistant bubbles
- `ChatPromptInput` owns the sticky composer
- `ChatSuggestions` renders prompt chips
- `ChatLoader` renders the assistant loading state
- `ChatPropertyResult` renders compact property blocks inside the thread
- `ChatFinanceCard` renders compact finance/ROI blocks inside the thread
- `ChatAuthGateNotice` renders the in-thread auth gate

These components intentionally avoid marketing sections, sidebars, and dashboard framing.
