# BuyerAssistantPage

- `index.tsx`: route-level buyer assistant shell and page composition.
- `useBuyerAssistant.ts`: conversation state, Convex assistant calls, and thread/history hydration.
- `BuyerAssistantComposer.tsx`: buyer composer derived from the workspace assistant input styling.
- `BuyerHistoryDrawer.tsx`: buyer thread history drawer.

This folder owns the chat-first buyer journey for `client-web`.
