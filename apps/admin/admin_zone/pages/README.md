# Admin Pages

- `DashboardPage/` renders the overview control plane.
- `UsersPage/` and `UserDetailPage/` handle operational user management.
- `OrganizationDetailPage/` provides deep drill-down visibility for one broker or developer organization.
- `PropertiesPage/` manages inventory CRUD and developer assignments.
- `OrdersPage/` manages deal/order status progression.
- `KnowledgePage/` manages knowledge pages feeding the agent.
- `DiagnosticsPage/` renders system health and failure telemetry.
