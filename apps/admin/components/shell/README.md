# Admin Shell

Workspace-inspired admin chrome for the protected `apps/admin` surface.

## Belongs Here
- the admin sidebar, desktop collapse behavior, and mobile drawer
- the shared admin top navbar
- shell-only layout constants and helper types

## Keep Separate
- business page composition stays in `admin_zone/pages`
- auth actions stay in `components/auth`
- generic UI primitives stay in `components/shared`
