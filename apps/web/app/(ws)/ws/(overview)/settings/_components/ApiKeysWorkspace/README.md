# ApiKeysWorkspace

Folder-backed API key management workspace for organization settings.

- `index.tsx`: thin page orchestrator.
- `catalog.ts`: permission catalogs and pure selection helpers.
- `useApiKeysWorkspace.ts`: local state and fetch side effects.
- `ApiKeysList.tsx`: current key table/list rendering.
- `CreateApiKeyDialog.tsx`: create-and-reveal modal flow.
