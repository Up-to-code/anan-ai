# WorkspaceAssistantComposer

- `index.tsx`: shared workspace assistant composer built on the prompt-input primitives.
- `WorkspaceAssistantAttachmentChips.tsx`: inline preview rail for pending image/file attachments before send.

This folder owns the workspace assistant composer experience only. It is the canonical agent-input surface for `/ws`, including text, image attachments, microphone controls, and workspace-aware helper copy.
