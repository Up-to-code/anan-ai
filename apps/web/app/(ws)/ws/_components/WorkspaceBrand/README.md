# WorkspaceBrand

Shared branded workspace primitives for `/ws`.

- `BrandSectionFrame.tsx`: landing-inspired section header shell.
- `BrandVectorPanel.tsx`: vector-first media panel for cards and hero summaries.
- `BrandStatStrip.tsx`: branded metric strip used by zone dashboards.
- `BrandWorkspaceTabs.tsx`: route-aware branded tab row.
- `BrandEmptyState.tsx`: neutral empty/relation-missing panel.
