# AgPropertyForm

Folder-backed project form wizard for workspace project create/edit flows.

- `index.tsx`: thin wizard orchestrator and layout shell.
- `types.ts`: public props and form data contracts.
- `shared.ts`: shared state type plus stable wizard constants.
- `utils.ts`: upload, gallery, and license helpers.
- `controls.tsx`: reusable local form UI building blocks.
- `useAgPropertyForm.ts`: local state, uploads, and submit handlers.
- `steps.tsx`: step-local sections for the six-step wizard.
