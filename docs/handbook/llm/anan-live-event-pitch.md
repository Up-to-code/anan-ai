# Anan Live Event Pitch

## Purpose

This document is the speaking version of Anan for live events, demos, founder introductions, and short public-stage pitches.

Use it when the goal is:

- to explain Anan clearly in person
- to introduce the company on stage
- to pitch at an event or meetup
- to give a short public presentation that normal people can understand quickly

This is not an investor memo.
This is not a deep product spec.
This is the live version of the company story.

## Core Message

Anan is an AI-first real estate operating system that connects the buyer journey with broker and developer execution in one system.

It starts with a buyer-side assistant for search, property understanding, financing, and handoff, then continues into an agent-first workspace where teams manage projects, offers, CRM, collaboration, and market work.

## The Problem In Simple Language

Real estate still feels broken because the journey is split across too many tools.

- discovery happens in one place
- financing happens somewhere else
- messaging moves to another channel
- follow-up lives in another tool
- the team loses context between every step

That creates friction for buyers, brokers, and developers.

## What Anan Does

Anan connects that journey into one flow.

On the buyer side, Anan uses an assistant-first experience to help people:

- search for properties
- understand the property itself
- review financing and bank options
- estimate mortgage or installment paths
- move into advisor or broker handoff

On the workspace side, Anan gives brokers and developers an agent-first operating surface where they can:

- work from the first screen
- manage projects
- create and review offers
- follow CRM and client context
- analyze brokers and market activity
- move work through drafts, approvals, and execution states

## What Makes Anan Different

Anan is not only:

- a chatbot
- a search app
- a finance tool
- a CRM
- a broker tool
- a marketplace

Anan connects these parts into one operating system.

That means the first conversation, the financing context, the team workflow, and the execution layer all stay connected.

## Vision

The vision of Anan is to make real estate work like one connected operating system instead of a collection of disconnected tools.

When we say “one system” or “one screen,” we do not mean that every action must happen on one literal page.

We mean:

- one connected flow
- one shared context
- one operating logic from demand to execution

The assistant should not stop at answering questions.
It should help move the work forward.
The workspace should not start with menus alone.
It should start with an agent that helps the team operate.
